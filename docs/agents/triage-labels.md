# Triage Labels

Map canonical triage roles to labels in the self-hosted Plane project.

| Canonical role | Plane label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the ticket |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Resolve label names to project label UUIDs before applying them. Preserve unrelated labels. Edit the Plane label column to change the vocabulary later.
